# 5 分鐘上手 ChengYoung

ChengYoung 是執行在你自己電腦上的本機優先 AI 代理程式。它讀寫你開啟的那個目錄、執行你允許的指令，模型可以是安裝在本機的，也可以接上你已經付費的提供者。

開始使用不需要註冊：沒有帳號，也沒有登入頁。

五分鐘足以走完讓它真正有用的四件事：

- 選定驅動對話的模型
- 讓它指向一個目錄
- 交給它第一個任務
- 需要觸及目錄之外時，安裝一個擴充功能

## 1. 選定模型

首次啟動會詢問你想怎麼執行對話，兩條路都能走，之後隨時可以更換。

**只在本機執行，不需要帳號** —— 選擇「使用本機模型」。ChengYoung 會列出適合你這台機器的下載項目，開始下載前先顯示檔案大小，下載過程中顯示進度；下載完成後即可直接使用。提示詞、檔案與回答都留在本機。

**接上提供者** —— 選擇「連線到提供者」，從你已在使用的廠商中挑一個，再把該廠商主控台裡的 API 金鑰貼進來。金鑰儲存在本機設定中。

之後想換模型，用聊天視窗底部的模型選擇器，或開啟「設定 → 模型」並點選「切換模型」。下載項目、磁碟用量與 Hugging Face 搜尋框都在「設定 → 本機推論」；想騰出空間時也在那裡刪除不再需要的模型。

本機推論適合離線場合與不便外傳的資料，但它受硬體限制：比可用記憶體還大的模型會跑得很慢甚至載入失敗，長對話也會比雲端模型更早佔滿上下文視窗。

已經有現成的模型檔案？預設會掃描 Hugging Face 快取（`~/.cache/huggingface/hub`）與應用程式的資料目錄 `models`；你也可以在設定目錄的 `model_paths.yaml` 裡登記更多目錄（Windows 為 `%APPDATA%\Block\goose\config\`，Linux / macOS 為 `~/.config/goose/`）。這樣找到的模型會出現在同一份模型清單中。

## 2. 讓它指向一個目錄

ChengYoung 在一個工作目錄內運作。首頁會顯示目前生效的那一個：頂端列是目錄名稱，游標停留可看到完整路徑。

- 想換目錄，點選聊天輸入框底部的目錄名稱，選擇「選擇目錄…」，或直接輸入路徑。
- 同一個選單裡還有最近使用過的目錄、目前儲存庫的 Git 工作區，以及正在使用的目錄。
- 除非你明確要求去別處，代理程式讀寫的一切都以這個工作目錄為基準。

目錄不會上傳：檔案留在原處，任務也只觸碰它真正需要的那部分。

## 3. 交給它第一個任務

在輸入框裡直接寫，或從首頁的四張卡片起手 —— 快速瀏覽目錄並說明結構、掃描文件產生摘要、檢查程式碼的潛在問題、依目前變更草擬提交訊息。卡片只會把指令填進輸入框，你可以改好措辭再送出。

第一次使用值得知道的幾件事：

- ChengYoung 透過工具讀寫檔案、執行指令，因此答案是你可以逐條跟讀的步驟鏈，而不是一整段文字。
- 涉及敏感操作時，會先彈出授權確認。看清楚內容再允許或拒絕；如果你希望更少被打斷，「設定 → 聊天」裡有批准模式。
- 把檔案拖到輸入框即可隨下一則訊息一起交給它。
- 在專案裡放一份 `.goosehints`（或寫一份全域的）把慣例與建置指令寫一次，不必每條提示都重複。
- 執行中的回合隨時可以中止，對話紀錄兩邊都會保留。

## 4. 需要觸及目錄之外時，安裝一個擴充功能

擴充功能就是 Model Context Protocol（MCP）伺服器：一個本機程序或遠端位址，把額外的工具交給模型。它負責目錄本身涵蓋不到的部分 —— 問題追蹤、資料庫、瀏覽器。

1. 開啟左側導覽中的「擴充功能」。
2. 點選「新增自訂擴充功能」。
3. 說明如何連線：`stdio` 指令、`streamable_http` 位址，或隨應用程式一起提供的內建擴充功能。
4. 儲存，然後在清單中啟用它。

擴充功能以你的身分行事，所以只保留你正在使用的那些處於啟用狀態。細節見該畫面自帶的「擴充功能」說明。

## 接下來去哪裡

| 你想做 | 開啟 |
| --- | --- |
| 把一套固定流程重複使用 | 工作流程 |
| 讓 ChengYoung 記住你的慣例 | 技能，或一份 `.goosehints` |
| 讓某件事按計畫自動執行 | 排程器 |
| 找回之前的對話 | 工作階段紀錄 |
| 改語言、主題、更新或隱私選項 | 設定 → 應用程式 |

整條循環就這些：選模型、選目錄、提出要求，任務超出目錄範圍時再擴充。
