# 擴充功能

擴充功能即 Model Context Protocol（MCP）伺服器。ChengYoung 會將它作為本機程序啟動，或連線到遠端位址，再將它對外提供的工具、提示詞與資源交給模型使用。

## 擴充功能帶來什麼

| 組成 | 模型取得的能力 |
| --- | --- |
| 工具 | 可呼叫的動作，例如執行指令、查詢介面、編輯檔案 |
| 提示詞 | 可在工作階段中重複使用的現成指令 |
| 資源 | 模型按需要讀取的檔案或紀錄 |

擴充功能既不是技能，也不是應用：技能是為 ChengYoung 撰寫的可重複使用工作流程，應用是為某項任務產生的小介面；擴充功能解決的是「接入既有軟體」。

## 新增擴充功能

1. 開啟 **設定 → 擴充功能**。
2. 點選 **新增自訂擴充功能**。
3. 選擇接入方式：
   - `stdio` —— ChengYoung 在本機執行一條指令，例如 `npx -y @modelcontextprotocol/server-filesystem /path`。
   - `streamable_http` —— 連線到你自建或信任的位址。
   - `builtin` —— 隨應用程式一併提供的擴充功能。
4. 伺服器需要時，填寫環境變數、請求標頭與逾時時間。
5. 儲存，然後在清單中啟用它。

`stdio` 擴充功能在本機執行，首次啟動可能需要連線下載相依套件，之後使用本機快取。

**填寫提示**：類型選 `stdio` 時，「指令」框填本機指令（如 `npx -y some-mcp-server`），不要填網址；類型選 `streamable_http` 時，「端點」框填以 `http://` 或 `https://` 開頭的位址。填錯形態會被表單直接攔截並提示——例如把網址填進指令框，啟動時會報「os error 123」這類讓人困惑的錯誤。

## 管理擴充功能清單

- 在清單中關閉開關即可讓新的工作階段不再使用它，設定會保留。
- 開啟同一項目可修改指令、位址或環境變數。
- 不再使用的擴充功能可以刪除。

## 伺服器從哪裡來

MCP 伺服器由各自的作者發佈：社群專案、廠商、內部團隊。請從你信任的伺服器文件中複製指令或位址，並在啟用前查看其原始碼與授權 —— 擴充功能可以代表你讀取檔案、執行指令、呼叫介面。

## 權限與安全

當工具呼叫涉及敏感操作時，ChengYoung 會先顯示授權確認。首次使用某個擴充功能時請仔細閱讀該確認內容，並只保留你正在使用的擴充功能處於啟用狀態。

## 技能與擴充功能目錄

不知道裝什麼？官網的「技能與擴充功能」頁面（chengyoung.com/extensions/）收錄了經人工核驗的第三方擴充功能，每個條目都附安裝步驟、所需權限、憑證要求與資料去向揭露；標註「已完成相容性測試」的條目表示在指定版本與環境完成了安裝與工具呼叫測試（不代表安全稽核）。
