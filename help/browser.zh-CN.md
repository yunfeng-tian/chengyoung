# 关于内嵌浏览器

内嵌浏览器把第三方网页与应用其余部分隔开。

## 页面在哪里运行

- 页面**嵌在应用里**：由**右栏**的「浏览器」视图承载，使用**独立的浏览器配置目录** —— 站点的 Cookie 与本地存储不会混进应用数据。
- 页面**访问不到应用或你的文件**：拿不到工作目录、设置与 Agent 工具。
- 流量**直连目标站点**：我们不做代理、不在路上记录，中间没有我们的服务器。

## 用新窗口打开的链接

要求开新窗口的链接（`target="_blank"`，或脚本里的 `window.open`）**在内嵌浏览器里不会打开** —— 页面停在原处、看起来「什么都没发生」。这里的内核会把这类请求丢掉，所以我们也没法把内容显示在同一个视图里。

需要打开这类链接时，走页面上方工具条里的那条路：

- **用系统浏览器打开**（交给你的默认浏览器），或
- 复制地址后粘进地址栏。

## Agent 能对页面做什么

浏览器控制**默认关闭**。要让 Agent 碰到页面，必须同时满足两条：

1. 在**设置 → 浏览器控制**里打开开关；
2. 该站点的域名在授权列表里。

两条都满足后，Agent 可以读取页面文本、点击页面元素，以及后退 / 前进 / 刷新。它读到的内容会进入模型上下文：本地模型不出本机；但如果你使用云端提供商，内容会发给该提供商。页面文本不会以明文写进日志。

### 输入写入与提交

往输入框里写内容、提交表单是**另一个开关**（同样默认关闭）—— 你可能希望 Agent 能点击，但不要替你填任何东西。

- 每一次写入、每一次提交都会先在右栏弹出**确认条**，把站点、字段与将要写入的文本展示出来。未作答或超时一律按**拒绝**处理。
- 输入可以选择**本会话总是允许该站点**；该授权只存在于当前浏览器页面的会话里，页面一关即失效。
- **提交永远逐次确认**（没有「总是允许」），且同一站点在同一个会话里**只能提交一次**。
- 密码框、一次性验证码、卡号，以及被禁用或只读的字段，都在**页面自身**就被拒绝 —— 文本根本到不了那些字段。
- 只操作顶层文档（不进 iframe、不穿透 shadow root），Agent 写入的文本**不会写进日志**。

### 列出输入框

Agent 还可以**列出本页你能看见的输入框** —— 只给稳定选择器，绝不含你已经填进去的内容，也不含密码 / 一次性验证码 / 卡号字段。这样它能找到要输入的目标字段。

我们不上传这些内容：不采集页面内容，也没有任何使用统计。
