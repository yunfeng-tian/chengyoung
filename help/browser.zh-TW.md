# 關於內嵌瀏覽器

內嵌瀏覽器把第三方網頁與應用其餘部分隔開。

## 頁面在哪裡執行

- 頁面**嵌在應用裡**：由**右欄**的「瀏覽器」檢視承載，使用**獨立的瀏覽器設定目錄** —— 網站的 Cookie 與本機儲存不會混進應用資料。
- 頁面**存取不到應用或你的檔案**：拿不到工作目錄、設定與 Agent 工具。
- 流量**直連目標網站**：我們不做代理、不在路上記錄，中間沒有我們的伺服器。

## 要求開新視窗的連結

要求開新視窗的連結（`target="_blank"`，或指令碼裡的 `window.open`）**在內嵌瀏覽器裡不會開啟** —— 頁面停在原處、看起來「什麼都沒發生」。這裡的引擎會把這類要求丟掉，所以我們也無法把內容顯示在同一個檢視裡。

需要開啟這類連結時，走頁面上方工具列裡的那條路：

- **用系統瀏覽器開啟**（交給你的預設瀏覽器），或
- 複製位址後貼進位址欄。

## Agent 能對頁面做什麼

瀏覽器控制**預設關閉**。要讓 Agent 碰到頁面，必須同時滿足兩條：

1. 在**設定 → 瀏覽器控制**裡開啟開關；
2. 該網站的網域在授權清單裡。

兩條都滿足後，Agent 可以讀取頁面文字、點擊頁面元素，以及上一頁 / 下一頁 / 重新整理。它讀到的內容會進入模型上下文：本機模型不出本機；但如果你使用雲端提供者，內容會發給該提供者。頁面文字不會以明文寫進日誌。

### 輸入寫入與提交

把文字寫進輸入框、提交表單是**另一個開關**（同樣預設關閉）—— 你可能希望 Agent 能點擊，但不要替你填任何東西。

- 每一次寫入、每一次提交都會先在右欄彈出**確認列**，把網站、欄位與將要寫入的文字顯示出來。未作答或逾時一律視為**拒絕**。
- 輸入可以選擇**本工作階段總是允許此網站**；該授權只存在於目前瀏覽器頁面的工作階段裡，頁面一關即失效。
- **提交永遠逐次確認**（沒有「總是允許」），且同一網站在同一個工作階段裡**只能提交一次**。
- 密碼欄位、一次性驗證碼、卡號，以及被停用或唯讀的欄位，都在**頁面本身**就被拒絕 —— 文字根本到不了那些欄位。
- 只操作頂層文件（不進 iframe、不穿透 shadow root），Agent 寫入的文字**不會寫進日誌**。

### 列出輸入欄位

Agent 還可以**列出本頁你能看見的輸入欄位** —— 只給穩定選擇器，絕不含你已經填進去的內容，也不含密碼 / 一次性驗證碼 / 卡號欄位。這樣它能找到要輸入的目標欄位。

我們不上傳這些內容：不蒐集頁面內容，也沒有任何使用統計。
