# 扩展

扩展即 Model Context Protocol（MCP）服务器。ChengYoung 会把它作为本地进程启动，或连接到远端地址，再把它对外提供的工具、提示词与资源交给模型使用。

## 扩展带来什么

| 组成 | 模型获得的能力 |
| --- | --- |
| 工具 | 可调用的动作，例如执行命令、查询接口、编辑文件 |
| 提示词 | 可在会话中复用的现成指令 |
| 资源 | 模型按需读取的文件或记录 |

扩展既不是技能，也不是应用：技能是为 ChengYoung 编写的可复用工作流，应用是为某项任务生成的小界面；扩展解决的是「接入已有软件」。

## 添加扩展

1. 打开 **设置 → 扩展**。
2. 点击 **添加自定义扩展**。
3. 选择接入方式：
   - `stdio` —— ChengYoung 在本机执行一条命令，例如 `npx -y @modelcontextprotocol/server-filesystem /path`。
   - `streamable_http` —— 连接到你自建或信任的地址。
   - `builtin` —— 随应用一起提供的扩展。
4. 服务器需要时，填写环境变量、请求头与超时时间。
5. 保存，然后在列表中启用它。

`stdio` 扩展在本机运行，首次启动可能需要联网下载依赖，之后使用本地缓存。

## 管理扩展列表

- 在列表中关闭开关即可让新会话不再使用它，配置会保留。
- 打开同一条目可修改命令、地址或环境变量。
- 不再使用的扩展可以删除。

## 服务器从哪里来

MCP 服务器由各自的作者发布：社区项目、厂商、内部团队。请从你信任的服务器文档中复制命令或地址，并在启用前查看其源码与许可 —— 扩展可以代表你读取文件、执行命令、调用接口。

## 权限与安全

当工具调用涉及敏感操作时，ChengYoung 会先弹出授权确认。首次使用某个扩展时请认真阅读该确认内容，并只保留你正在使用的扩展处于启用状态。
