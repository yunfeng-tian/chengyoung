# 5 分钟上手 ChengYoung

ChengYoung 是运行在你自己电脑上的本地优先 AI 智能体。它读写你打开的那个目录、执行你批准的指令，模型既可以用装在本机的，也可以接你已经付费的提供商。

开始使用不需要任何注册：没有账号，也没有登录页。

五分钟足够走完让它真正有用的四件事：

- 选定驱动对话的模型
- 让它指向一个目录
- 交给它第一个任务
- 需要触及目录之外时，装一个扩展

## 1. 选定模型

首次启动会问你想怎么运行对话，两条路都能走，之后随时可以换。

**只在本机跑，不要账号** —— 选择「使用本地模型」。ChengYoung 会列出适配你这台机器的下载项，开始下载前先显示文件大小，下载过程中显示进度；下载完成后即可直接使用。提示词、文件与回答都留在本机。

**接一个提供商** —— 选择「连接提供商」，从你已在使用的厂商中挑一个，再把该厂商控制台里的 API 密钥粘贴进来。密钥保存在本机配置中。

之后想换模型，用聊天窗口底部的模型选择器，或打开「设置 → 模型」并点击「切换模型」。下载项、磁盘占用与 Hugging Face 搜索框都在「设置 → 本地推理」；想腾空间时也在那里删除不再需要的模型。

本地推理适合离线场景与不便外传的材料，但它受硬件限制：比可用内存还大的模型会跑得很慢甚至加载失败，长对话也会比云端模型更早占满上下文窗口。

已经有现成的模型文件？默认会扫描 Hugging Face 缓存（`~/.cache/huggingface/hub`）与应用的数据目录 `models`；你也可以在配置目录的 `model_paths.yaml` 里登记更多目录（Windows 为 `%APPDATA%\Block\goose\config\`，Linux / macOS 为 `~/.config/goose/`）。这样找到的模型会出现在同一个模型列表里。

## 2. 让它指向一个目录

ChengYoung 在一个工作目录内工作。启动页会显示当前生效的那一个：顶行是目录名，鼠标悬停可看到完整路径。

- 想换目录，点击聊天输入框底部的目录名，选择「选择目录…」，或直接输入路径。
- 同一个菜单里还有最近使用过的目录、当前仓库的 Git 工作树，以及正在使用的目录。
- 除非你明确要求去别处，智能体读写的一切都以这个工作目录为基准。

目录不会上传：文件留在原处，任务也只触碰它真正需要的那部分。

## 3. 交给它第一个任务

在输入框里直接写，或从启动页的四张卡片起手 —— 快速浏览目录并说明结构、扫描文档生成摘要、审查代码里的潜在问题、基于当前变更草拟提交信息。卡片只会把指令填进输入框，你可以改好措辞再发送。

第一次使用值得知道的几件事：

- ChengYoung 通过工具读写文件、执行命令，因此答案是你可以逐条跟读的步骤链，而不是一整段文字。
- 涉及敏感操作时，会先弹出授权确认。看清内容再批准或拒绝；如果你希望更少被打断，「设置 → 聊天」里有批准模式。
- 把文件拖到输入框即可随下一条消息一起交给它。
- 在项目里放一份 `.goosehints`（或写一份全局的）把约定与构建命令写一次，不用每条提示都重复。
- 运行中的回合随时可以中止，对话历史两边都会保留。

## 4. 需要触及目录之外时，装一个扩展

扩展就是 Model Context Protocol（MCP）服务器：一个本地进程或远端地址，把额外的工具交给模型。它负责目录本身覆盖不到的部分 —— 缺陷跟踪、数据库、浏览器。

1. 打开左侧导航中的「扩展」。
2. 点击「添加自定义扩展」。
3. 说明如何接入：`stdio` 命令、`streamable_http` 地址，或随应用一起提供的内置扩展。
4. 保存，然后在列表里启用它。

扩展以你的身份行事，所以只保留你正在使用的那些处于启用状态。细节见该页自带的「扩展」说明。
