# 求助与反馈 / Support

> 欢迎来到 ChengYoung 的反馈区。为了让你更快得到答案，请按下面的顺序来。

## 1. 先自救 / Try self-service first

- **应用内帮助中心**：点击对话页右上角的 ChengYoung 标志，16 篇离线文档覆盖安装、模型、工作流、常见问题。
- **常见问题（FAQ）**：见官网 [FAQ](https://chengyoung.com)。
- **已知问题**：见 [Releases](https://github.com/yunfeng-tian/chengyoung/releases) 的版本说明。

## 2. 报告问题 / Report a bug

点击下方按钮提交（需要 GitHub 账号）：

**[报障 → Issues](https://github.com/yunfeng-tian/chengyoung/issues/new?template=bug_report.yml)**

提交时请附：

- ChengYoung 版本号（设置 → 版本 中可见）
- 操作系统（Windows 10 / 11）
- 复现步骤与期望 / 实际行为
- 「**复制系统信息**」（设置 → App → 帮助与反馈）的内容——它**不包含会话内容**，可放心粘贴
- 需要排查具体对话时，可附**诊断 JSON**（聊天输入框旁的虫子图标）——⚠️ 它**包含当前会话消息、日志与配置文件原文（可能含 API Key）**，公开前请先自查：搜索 `key`、`token`、`password`、`Bearer`、`Users`，发现敏感内容先删除，**已泄露的 API Key 请立即轮换**

> ⚠️ Issue 是**公开**且长期可搜索的。如误发敏感内容，可以 @ 维护者协助编辑隐去。

## 3. 功能建议 / Feature requests

到 [Discussions · 功能建议](https://github.com/yunfeng-tian/chengyoung/discussions/ideas) 发帖，
说明你的使用场景与期望效果。

## 4. 使用交流 / Q&A

到 [Discussions · 使用问答](https://github.com/yunfeng-tian/chengyoung/discussions/q-a) 提问。

## 5. 邮件 / Email（与 GitHub 等效，任选其一）

发信至 **[support@chengyoung.com](mailto:support@chengyoung.com?subject=%5BChengYoung%5D)**
（点击自动带上 `[ChengYoung]` 主题前缀；也可手动添加，便于我们分流——该邮箱同时承接旗下其它产品）。

## 6. 安全漏洞 / Security issues

**请勿在此公开发布**。请参阅 [SECURITY.md](SECURITY.md) 的私密报告流程。

## 7. 社区规则 / Community guidelines

- 范围：ChengYoung 桌面应用（LicenseDesktop 产品的授权 / 退款请走其专属联系页）
- 语言：中文优先，英文也可
- 我们会尽快查看（通常 1–2 个工作日），但**不承诺具体的修复时间**
- 请勿粘贴 API Key、密码或对话原文；Issue 内容公开且永久可搜索

## English

Welcome to the ChengYoung feedback area. Please follow the order below for the fastest answer.

**1. Self-service first**: in-app help center (ChengYoung logo at the top-right of the chat page), the website FAQ, and the release notes for known issues.

**2. Report a bug**: use [the bug report form](https://github.com/yunfeng-tian/chengyoung/issues/new?template=bug_report.yml). Please include your ChengYoung version, OS, steps to reproduce, and the **Copy system info** content (Settings → App → Help & feedback — it contains **no conversation content**). For conversation-specific issues you may attach the **diagnostic JSON** (the bug icon next to the chat input) — ⚠️ it **contains the current conversation, logs, and your raw config file (possibly including API keys)**; search for `key` / `token` / `password` / `Bearer` / `Users` before posting publicly, and rotate any exposed keys immediately.

> Issues are **public and permanently searchable**. If you accidentally post something sensitive, mention the maintainers and we will help redact it.

**3. Feature requests**: post in [Discussions · Feature requests](https://github.com/yunfeng-tian/chengyoung/discussions/ideas).

**4. Q&A**: [Discussions · Q&A](https://github.com/yunfeng-tian/chengyoung/discussions/q-a).

**5. Email** (equivalent to GitHub, whichever you prefer): **support@chengyoung.com** — add the subject prefix `[ChengYoung]` so we can route it (this mailbox also handles our other products).

**Security vulnerabilities must not be disclosed publicly** — see [SECURITY.md](SECURITY.md).

**Community guidelines**: scope is the ChengYoung desktop app (LicenseDesktop licensing/refunds go to its own contact page); Chinese first, English welcome; we review reports within 1–2 business days but do not commit to fix timelines; do not paste API keys, passwords, or conversation text.
